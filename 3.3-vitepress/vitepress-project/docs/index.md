# <span style="color:#2e8b57;">SmartCart 🛒</span>

ברוך הבא ל־SmartCart – העוזר האישי שלך לקניות בסופר 👨‍🛒  

קניות מסודרות יותר, חכמות יותר — ופחות דברים שנשכחים.

---

## <span style="color:#2e8b57;">מה SmartCart יודע לעשות?</span>

- לתכנן רשימת קניות חכמה לפני שאתה יוצא לסופר  
- לחלק את הרשימה לפי מעברים בסופר (ירקות, מוצרי חלב, ניקיון וכו’)  
- לשמור היסטוריה של קניות ולראות על מה אתה מוציא הכי הרבה  
- לזהות מוצרים שאתה קונה הרבה — ולהזכיר לך להוסיף אותם לרשימה  
- לנתח תדירות וכמויות, ולפי מה שחסר בבית — להציע לך כמה לקנות בקנייה הבאה

---

## <span style="color:#2e8b57;">לבחור סופר ספציפי</span>

עם SmartCart אתה יכול לבחור את הסופר הקבוע שלך:

- לראות תמונות של המעברים והמדפים  
- “לעבור” על המדפים בצורה ויזואלית לפני הקנייה  
- להרגיש יותר בטוח שלא שכחת שום דבר 🙂
